Crop Yield Prediction using Machine Learning 🌾
A hands-on Python project predicting crop yields using supervised machine learning models. Cleaned and preprocessed raw agricultural data with Jupyter Notebook, Pandas, and NumPy. Trained and evaluated Linear Regression and Decision Tree models using Scikit-Learn to analyze environmental impacts on crop yield.

🛠️ Tech Stack
Language: Python 3
Environment: Jupyter Notebook
Libraries: Pandas, NumPy, Scikit-Learn, Matplotlib, Seaborn
📈 Methodology
Data Preprocessing: Handled missing values, standardized columns, and encoded categorical features.
Model Training: Implemented Linear Regression (baseline) and Decision Tree Regressor models.
Evaluation: Compared models using $R^2$ and Mean Squared Error (MSE).
