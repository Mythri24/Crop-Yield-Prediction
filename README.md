## 🎯 Project Overview

Predicting crop yield is a fundamental challenge in precision agriculture. By analyzing critical variables such as rainfall, temperature, and soil characteristics, this system uses supervised machine learning models to forecast agricultural outcomes accurately. 

> **Key Focus:** Bridging agricultural data science with scalable machine learning architectures.

---

## ⚡ Key Features

*   **🔍 Robust Data Preprocessing:** Seamless handling of missing dataset values, feature encoding, and column standardization using `Pandas` and `NumPy`.
*   **📊 Exploratory Data Analysis (EDA):** Visualizing complex correlations between climate metrics (e.g., moisture, temperature) and crop yield.
*   **🤖 Double-Model Pipeline:** Implementing and comparing two different supervised learning approaches:
    *   **Linear Regression** (for modeling linear relationships)
    *   **Decision Tree Regressor** (for capturing non-linear patterns)
*   **📈 Performance Evaluation:** Benchmarking models using Mean Squared Error (MSE) and $R^2$ scores to ensure maximum predictive reliability.
